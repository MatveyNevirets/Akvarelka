# Акварелька · Казань

Готовый статический сайт без зависимостей. Запуск: `npm run dev`, адрес http://127.0.0.1:5187. Проверка JavaScript: `npm run check`. Для обычного хостинга загрузите содержимое `dist/`.

## Заявки

Форма проверяет имя, возраст, направление и полный телефон, создаёт сообщение и ссылку на WhatsApp +7 917 266-65-97. Пользователь сам отправляет сообщение. Данные не сохраняются и автоматически не передаются. Есть предпросмотр и копирование текста. Место будущего подключения CRM/webhook отмечено в `dist/app.js`. Серверная интеграция не настроена; не добавляйте секреты в клиентский код.

Маска в `dist/phone-mask.mjs` показывает номер как `+7 (927) 123-45-67`, поддерживает вставку с 8/7/+7, автозаполнение, выделение и редактирование середины номера. Скрытое поле `phone` содержит нормализованный номер `+79271234567`. Видимое поле имеет `autocomplete="tel"` и телефонную клавиатуру.

Направления выбираются нативными радиокнопками, оформленными как переключатели в текущей палитре. Поддерживается клавиатура. Тематические CTA выбирают своё направление, общие — консультацию; после любого CTA выбор можно изменить вручную. Подсказки об ошибках появляются после выхода из поля или попытки подготовить сообщение. Изменение данных скрывает устаревшее сообщение.

## Микроанимации

`dist/motion.mjs` добавляет однократное появление при прокрутке и stagger до 120 мс, мягкое появление фото, открытие/закрытие FAQ с поддержкой повторных кликов, параллакс стикера до 6 px только на desktop с точным указателем. CSS дополняет hover/focus кнопок, карточек и направлений. Постоянных циклических анимаций нет. На touch упрощены эффекты, на мобильном убраны задержки и параллакс. `prefers-reduced-motion` поддерживается при загрузке и изменении настройки. Без IntersectionObserver контент остаётся видимым. Библиотек анимации и новых runtime-зависимостей нет.

## Проверка

`npm run check` проверяет синтаксис всех клиентских модулей. `npm test` запускает DOM-тесты на Node.js: вставка и редактирование телефона, валидация, все виды CTA, ручная смена направления, нормализованное сообщение, меню, reveal, FAQ и переключение reduced-motion. Для тестов используется только dev-зависимость `happy-dom` (`npm ci` после загрузки проекта). Сам сайт статический и не требует компиляции или установки пакетов для работы.

Локальные ресурсы, якоря, HTML-структура и HTTP-ответ проверены. Сервер отдаёт `.mjs` с JavaScript MIME. В текущей среде нет подключённого браузера, поэтому визуальные desktop/mobile, фактический FPS, консоль настоящего браузера и работу WhatsApp на устройствах проверить не удалось; DOM-тесты не заменяют эти проверки.
